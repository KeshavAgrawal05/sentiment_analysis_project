# 🐦 Twitter Sentiment Analysis using NLP

> A production-ready machine learning system that classifies tweets as **Positive**, **Negative**, or **Neutral** — built with Python, scikit-learn, NLTK, and Streamlit.

---

## 📌 Project Overview

This project demonstrates an end-to-end NLP pipeline for sentiment analysis on Twitter data. It covers data preprocessing, feature extraction, model training, evaluation, and deployment through an interactive Streamlit web application.

**Key highlights:**
- Reusable `TextPreprocessor` class with full NLTK pipeline
- TF-IDF feature extraction (unigrams + bigrams)
- Two trained classifiers compared: Logistic Regression & Naive Bayes
- Model bundle saved as a single `.pkl` (vectoriser + model + preprocessor + label map)
- Clean Streamlit UI with confidence scores and history tracking

## ⚙️ Installation

### 1. Clone the repository
```bash
git clone https://github.com/your-username/twitter-sentiment-analysis.git
cd twitter-sentiment-analysis
```

### 2. Create a virtual environment (recommended)
```bash
python -m venv venv

# Activate
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Download NLTK data
```python
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('wordnet'); nltk.download('omw-1.4')"
```

### 5. (Optional) Download spaCy English model
```bash
python -m spacy download en_core_web_sm
```

## 🏗️ Technical Architecture

```
Raw Tweet Text
     │
     ▼
TextPreprocessor
  • Lowercase
  • Remove URLs / @mentions / #hashtags
  • Remove punctuation & numbers
  • Tokenise (NLTK word_tokenize)
  • Remove stopwords (NLTK English corpus)
  • Lemmatise (WordNetLemmatizer)
     │
     ▼
TfidfVectorizer
  • 10,000 features
  • Unigrams + bigrams
  • Sublinear TF (log normalisation)
     │
     ▼
Classifier (Logistic Regression / Naive Bayes)
     │
     ▼
Sentiment Label + Confidence Score
```

## 🔧 Configuration & Customisation

### Use your own dataset
Replace `data/tweets.csv` with any CSV containing `text` and `sentiment` columns:
```csv
text,sentiment
"I love this!",positive
"Terrible product.",negative
"It arrived.",neutral
```

### Change model hyperparameters
Edit `src/train.py` → `get_models()` and `build_tfidf_vectorizer()`:
```python
# Increase TF-IDF vocabulary
vectorizer = TfidfVectorizer(max_features=20_000, ...)

# Tune Logistic Regression regularisation
LogisticRegression(C=5.0, ...)
```
