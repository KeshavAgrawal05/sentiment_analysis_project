# 🐦 Twitter Sentiment Analysis using NLP

> A production-ready machine learning system that classifies tweets as **Positive**, **Negative**, or **Neutral** — built with Python, scikit-learn, NLTK, and Streamlit.

---

## 📌 Project Overview

This project demonstrates an end-to-end NLP pipeline for sentiment analysis on Twitter data. It covers data preprocessing, feature extraction, model training, evaluation, and deployment through an interactive Streamlit web application.

**Key highlights:**
- Reusable `TextPreprocessor` class with full NLTK pipeline
- TF-IDF feature extraction (unigrams + bigrams)
- Two trained classifiers compared: Logistic Regression & Naive Bayes
- Model bundle saved as a single `.pkl` (vectoriser + model + preprocessor + label map)
- Clean Streamlit UI with confidence scores and history tracking
